                          QUICK START (3 STEPS)
================================================================================

1. INSTALL DEPENDENCIES:
   npm install

2. SETUP FIREBASE:
   - Create Firebase project
   - Enable Email/Password auth
   - Create Firestore database
   - Copy credentials to .env.local

3. RUN LOCALLY:
   npm run dev
   Visit http://localhost:3000
