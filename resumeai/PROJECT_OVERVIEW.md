## 🚀 Quick Start

```bash
# Step 1: Install
npm install

# Step 2: Setup Firebase
# - Create project at firebase.google.com
# - Enable Email/Password auth
# - Create Firestore database
# - Copy credentials to .env.local

# Step 3: Run
npm run dev
# Visit http://localhost:3000
```
